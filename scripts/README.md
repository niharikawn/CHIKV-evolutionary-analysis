# Scripts

This directory contains scripts used for the bioinformatics analysis of Chikungunya virus (CHIKV) whole-genome sequences.

## Organization

Scripts are organized according to the major stages of the analysis workflow:

- Data curation and metadata processing
- Sequence filtering
- Redundancy removal
- Multiple sequence alignment
- Phylogenetic analysis
- Temporal analysis
- Bayesian evolutionary analysis
- Selection pressure analysis
- Recombination analysis

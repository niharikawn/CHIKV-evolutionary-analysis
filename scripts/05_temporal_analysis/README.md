# Temporal Analysis

This directory contains information related to temporal signal analysis of CHIKV whole-genome sequences.

## Tool

- TempEst

## Purpose

TempEst was used to assess the temporal signal and clock-like behavior of the CHIKV dataset before Bayesian evolutionary analysis.

## Analysis

The maximum-likelihood phylogenetic tree generated using IQ-TREE was analyzed together with sequence collection dates.

The correlation between root-to-tip genetic divergence and sampling time was assessed.

## Result

Correlation coefficient (r): 0.1652

R²: 0.0273

Estimated evolutionary rate: 1.4235 × 10⁻³ substitutions/site/year

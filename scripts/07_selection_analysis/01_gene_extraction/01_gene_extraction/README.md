# Gene Extraction

This directory contains the steps used to extract individual CHIKV genes for gene-wise selection pressure analysis.

## Tool

- SeqKit

## Genes analyzed

- nsP1
- nsP2
- nsP3
- nsP4
- Capsid
- E3
- E2
- E1

Gene-specific sequences were extracted from the CHIKV coding sequence dataset for downstream sequence processing and codon-aware alignment.

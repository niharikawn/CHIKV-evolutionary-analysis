# Data Curation

This directory contains scripts used for collecting, organizing, and curating Chikungunya virus (CHIKV) whole-genome sequence data.

## Purpose

The data curation stage prepares publicly available CHIKV sequences for downstream evolutionary and phylogenetic analyses.

## Main steps

- Sequence and metadata collection
- Collection-date filtering
- Removal of passaged isolates
- Sequence quality and length filtering
- Metadata consistency checks
- Preparation of the curated dataset for downstream analysis
